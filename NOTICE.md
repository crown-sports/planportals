# Provenance and external assets

The package was independently implemented around explicit geometry, observations and result contracts. An earlier private application contained an opening-processing prototype; its model/network code, vendor implementations, cloud services, business APIs, examples, datasets and Git history are not redistributed.

Connected components, principal-axis fitting, point-in-polygon tests and breadth-first graph search are established techniques. NumPy, OpenCV and Pillow retain their own licenses. Upstream models and semantic labels are caller-provided and keep their own redistribution conditions.

The original `examples/demo.png` is generated from source geometry and actual library results. It is an illustration of conditional graph construction, not a real drawing or an end-to-end door/window detection benchmark. No real datasets, annotations or weights are included. See [methods](docs/methods.md) and [validation](docs/validation.md).

`examples/workflow.png` is rendered from the generated, model-free four-package walkthrough. The source mask, labels and JSON come from actual tool outputs, not real drawings or detector predictions. The renderer is [render_workflow.py](https://github.com/crown-sports/planportals/blob/main/tools/render_workflow.py).
