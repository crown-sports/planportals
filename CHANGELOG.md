# Changelog

## 0.2.1 — 2026-10-23 (prerelease)

- Report empty or corrupt label archives as input errors with exit code 2.

- Refuse build outputs that would overwrite scene or upstream inputs, including hard links and symlinks.

## 0.2.0 — 2026-10-22
- Include the required `.gitignore` in source distributions and verify the unpacked archive in CI.
- Preserve one-pass Python iterables of blocked openings, so closure scenarios cannot silently discard a generator of door IDs.
- Add immutable door-closure scenarios to routing and an `access` report with baseline reachability, newly isolated rooms, remaining routes, and optional review-gate exit codes.

## 0.1.0 — 2026-10-09

Initial experimental release. Independent geometry and evidence processing, local CLI and generated demonstration. See the README and validation protocol for supported inputs and limits.
