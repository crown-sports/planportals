# Security policy

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/crown-sports/planportals/security/advisories/new). Include a minimal generated reproduction, affected version and impact. Keep private drawings, annotations, credentials and exploit details out of public issues.

The latest experimental 0.x release receives fixes on a best-effort basis. This is a local library, not a hosted upload service; applications must apply their own file-size limits, access controls and process isolation. There is no support SLA.
